# Documentation language

- Keep GitHub's default `README.md` in English. English is the primary documentation language.
- Provide Japanese as the secondary version in `README.ja.md`, with reciprocal language links near the top of both files.
- Update both README versions together when features, setup, requirements, limitations, or verification status change. Do not replace the primary README with Japanese-only content.
- Label links to Japanese-only supporting documentation so English readers know the target language.
- Preserve accurate distinctions between automated tests, Live hardware verification, and untested platforms. Documentation-only changes do not require rebuilding devices.
